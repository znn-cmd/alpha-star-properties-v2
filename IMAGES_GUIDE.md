# Руководство по замене изображений

## 📸 Текущее состояние

Все изображения в проекте заменены на SVG-заглушки. Это позволяет:
- ✅ Сайт работает без внешних зависимостей
- ✅ Быстрая загрузка страниц
- ✅ Визуально понятно, где какие изображения нужны
- ✅ Легко заменить на реальные фото

## 🗂️ Типы заглушек

### 1. Изображения недвижимости
**Расположение:** `/public/images/placeholders/property.svg`  
**Используется в:**
- Карточки объектов
- Галереи на странице объекта
- Рекомендуемые объекты

**Размер:** 800x600px

### 2. Фото команды
**Расположение:** `/public/images/placeholders/team.svg`  
**Используется в:**
- Главная страница (секция команды)
- Страница "О нас"

**Размер:** 400x500px (портрет)

### 3. Изображения статей
**Расположение:** `/public/images/placeholders/article.svg`  
**Используется в:**
- Список статей в журнале
- Обложки статей

**Размер:** 800x400px

### 4. Изображения районов
**Расположение:** `/public/images/placeholders/area.svg`  
**Используется в:**
- Сетка районов Дубая на главной

**Размер:** 600x400px

### 5. Hero-изображения
**Расположение:** `/public/images/placeholders/hero.svg`  
**Используется в:**
- Главный экран (Hero section)
- Заголовки страниц About, Contact и др.

**Размер:** 1920x600px

## 🔄 Как заменить изображения

### Вариант 1: Локальные файлы (рекомендуется для начала)

1. **Подготовьте изображения:**
   ```
   public/
     images/
       properties/
         property-1.jpg
         property-2.jpg
         ...
       team/
         alexander-petrov.jpg
         marina-ivanova.jpg
         ...
       articles/
         article-1.jpg
         ...
       areas/
         downtown-dubai.jpg
         dubai-marina.jpg
         ...
       hero/
         home-hero.jpg
         about-hero.jpg
   ```

2. **Обновите `data/properties.json`:**
   ```json
   "images": [
     "/images/properties/property-1.jpg",
     "/images/properties/property-2.jpg"
   ]
   ```

3. **Обновите страницы:**
   - `app/[locale]/page.tsx` - команда, районы, hero
   - `app/[locale]/about/page.tsx` - команда, hero
   - `app/[locale]/journal/page.tsx` - статьи

### Вариант 2: CDN (для production)

1. **Загрузите на CDN:**
   - Cloudinary
   - AWS S3 + CloudFront
   - Vercel Blob
   - ImgIX

2. **Обновите next.config.js:**
   ```js
   images: {
     remotePatterns: [
       {
         protocol: 'https',
         hostname: 'your-cdn.com',
       },
     ],
   }
   ```

3. **Замените URL в файлах:**
   ```json
   "images": [
     "https://your-cdn.com/properties/property-1.jpg"
   ]
   ```

## ⚡ Оптимизация изображений

### Перед загрузкой:

1. **Сожмите изображения:**
   - Онлайн: TinyPNG, Squoosh
   - CLI: `sharp`, `imagemagick`

2. **Конвертируйте в WebP:**
   ```bash
   # Пример с imagemagick
   convert input.jpg -quality 85 output.webp
   ```

3. **Создайте responsive версии:**
   - Small (800px): для мобильных
   - Medium (1200px): для планшетов
   - Large (1920px): для десктопа

### Автоматическая оптимизация:

Next.js автоматически оптимизирует изображения через компонент `Image`:
- Ленивая загрузка
- Адаптивные размеры
- Современные форматы (WebP, AVIF)

## 🎨 Советы по фотографиям

### Недвижимость:
- Чистые, светлые фото
- Профессиональная съемка или качественные стоки
- Показывайте лучшие ракурсы
- Минимум 2, лучше 4-6 фото на объект

### Команда:
- Единый стиль фотографий
- Профессиональный фон (светлый или брендовый)
- Формальная деловая одежда
- Одинаковое освещение

### Статьи:
- Релевантные теме
- Высокое разрешение
- Привлекательные, но не отвлекающие
