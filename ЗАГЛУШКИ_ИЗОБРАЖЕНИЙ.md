## ✏️ Как заменить на реальные фото

### Вариант 1: Локальные файлы (проще для начала)

1. **Создайте папки:**
   ```
   public/
     images/
       properties/
       team/
       articles/
       areas/
       hero/
   ```

2. **Добавьте ваши фото:**
   ```
   properties/
     property-1.jpg
     property-2.jpg
     ...
   team/
     alexander-petrov.jpg
     marina-ivanova.jpg
     ...
   ```

3. **Обновите пути:**
   
   В `data/properties.json`:
   ```json
   "images": [
     "/images/properties/property-1.jpg",
     "/images/properties/property-2.jpg"
   ]
   ```
   
   В `app/[locale]/page.tsx` (команда):
   ```typescript
   image: '/images/team/alexander-petrov.jpg'
   ```

### Вариант 2: Использовать CDN

1. **Загрузите на:**
   - Cloudinary (бесплатно до 25GB)
   - AWS S3
   - Vercel Blob

2. **Обновите `next.config.js`:**
   ```js
   images: {
     remotePatterns: [
       {
         protocol: 'https',
         hostname: 'your-cdn.com',
       },
     ],
   }
   ```

3. **Замените URL:**
   ```json
   "images": [
     "https://your-cdn.com/properties/1.jpg"
   ]
   ```
