## ✅ ШАГ 1: Git репозиторий создан!

## 📦 ШАГ 2: Загрузить на GitHub

### Вариант A: Через скрипт (самый быстрый)

**Дважды кликните:** `setup-github.bat`

Следуйте инструкциям:
1. Создайте репозиторий на GitHub
2. Введите ваш username
3. Готово!

### Вариант B: Вручную

1. **Откройте:** https://github.com/new

2. **Заполните:**
   - Repository name: `alpha-star-properties-v2`
   - Description: `Premium real estate website`
   - Выберите Private/Public
   - **НЕ добавляйте** README, .gitignore, license

3. **Нажмите:** "Create repository"

4. **Выполните в PowerShell:**
   ```powershell
   cd "C:\Users\zaice\Desktop\alpha v2"
   git remote add origin https://github.com/ВАШ_USERNAME/alpha-star-properties-v2.git
   git branch -M main
   git push -u origin main
   ```

## 🌐 ШАГ 3: Деплой на Vercel

### Вариант A: Через скрипт (рекомендуется)

**Дважды кликните:** `setup-vercel.bat`

Скрипт:
- Установит Vercel CLI (если нужно)
- Авторизует вас
- Задеплоит проект

### Вариант B: Через веб-интерфейс (проще)

1. **Откройте:** https://vercel.com/signup

2. **Войдите через GitHub**

3. **Нажмите:** "Add New..." → "Project"

4. **Выберите:** `alpha-star-properties-v2`

5. **Configure Project:**
   - Framework: Next.js (автоматически)
   - Root Directory: ./
   - Остальное оставьте как есть

6. **Нажмите:** "Deploy"

7. **Ждите 2-3 минуты** ☕

### Вариант C: Через CLI вручную

```powershell
# Установите Vercel CLI
npm i -g vercel

# Авторизуйтесь
vercel login

# Деплой
vercel

# Production
vercel --prod
```

## 🔧 Настройки после деплоя

### Environment Variables (если нужны):

1. Откройте проект в Vercel
2. **Settings** → **Environment Variables**
3. Добавьте:
   ```
   SITE_URL = https://alpha-star-properties-v2.vercel.app
   NEXT_PUBLIC_SITE_URL = https://alpha-star-properties-v2.vercel.app
   ```

### Свой домен (опционально):

1. **Settings** → **Domains**
2. **Add** → введите ваш домен
3. Следуйте инструкциям

## 🆘 Проблемы?

### "git: command not found"
- Установите Git: https://git-scm.com/download/win

### "vercel: command not found"
- Запустите `setup-vercel.bat` - он установит автоматически

### Ошибка при push
- Проверьте что создали репозиторий на GitHub
- Убедитесь что ввели правильный username

### Сайт не работает
- Проверьте логи в Vercel Dashboard
- Убедитесь что `npm run build` работает локально
